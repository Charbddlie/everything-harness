## 公式呈现

- CLI 对话使用 Unicode 公式：上下标可写 `xᵢ`、`x²`，复杂下标用 `s_{t+1}`；分数用 `(a + b) / c`，条件概率用 `π(a∣s)`，范数用 `‖x‖`。行内加反引号，复杂公式放代码块，符号说明单列。
- 文件使用 LaTeX：Markdown 用 `$...$`、`$$...$$`；`.tex` 用 `\(...\)`、`\[...\]`，多行用 `aligned` 或 `align`，遵循目标渲染器约定。分式用 `\frac`，条件竖线用 `\mid`，范数用 `\lVert`、`\rVert`。
- 渲染公式直接写入正文；展示 LaTeX 源码时使用代码围栏。对话与文件分别采用对应格式。
